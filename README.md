# Mi Día Saludable

Versión inicial de una PWA de código abierto para registrar comidas, agua, actividades, sueño, alcohol, peso y estado de ánimo. También permite guardar una meta de peso y exportar registros CSV.

## Publicación en GitHub Pages

1. Crea un repositorio público llamado `mi-dia-saludable`.
2. Sube todos los archivos de esta carpeta **sin incluir una carpeta contenedora**: `index.html`, `manifest.webmanifest`, `sw.js`, `icon.svg`, `README.md` y `LICENSE`.
3. En Settings → Pages, elige Deploy from a branch, `main` y `/(root)` y pulsa Save.
4. Abre `https://TU-USUARIO.github.io/mi-dia-saludable/`.

## Privacidad y limitaciones

Los registros se guardan únicamente en el navegador mediante localStorage. No se sincronizan entre dispositivos y podrían perderse si se borran los datos del navegador. Usa Exportar CSV para guardar copias. No introduzcas claves secretas o información personal en el repositorio público. OCR, reconocimiento de productos, integración de IA, recordatorios avanzados y sincronización privada aún no están implementados.
